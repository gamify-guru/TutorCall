Ключи · Class Mission

1. Match (главный вопрос заметки)

  1. The key tag → The spare key
  2. One shadow? → Three ghosts — or one
  3. The folded eye → The eye-symbol note
  4. Four movements → The spare key

2. Highlight — 7 фраз too / enough

too dark; small enough; too close; far enough apart; too thin; neat enough; enough time.

Отвлекающие: very quietly, brown coat, almost together, very soon, rather strange, all at once, really odd.

3. Useful information

  • Note 01 The key tag — только key
  • Note 02 One shadow? — только ghosts
  • Note 03 The folded eye — только eye
  • Note 04 Four movements — key и ghosts

4. Connect details

  • Received the spare key from Agnes → Mr Abernathy
  • Heard three voices near the music room → Lila Moreau
  • Owned the blue notebook with the folded note → Theo Hale
  • Always crosses a capital I → Professor Voss

Ключи · Homework

A. Timeline (раньше → позже)

  1. 4:00 The closed ink bottle
  2. 4:05 One note, three times
  3. 4:09 The key ledger
  4. 4:11 An older eye
  5. 4:14 The lamp test

B. Grammar

  1. The ink was too faint to read.
  2. Lila was careful enough to hear the echo.
  3. The key was too small for the archive door.
  4. Voss did not write clearly enough.
  5. There were too many shadows for one lamp.
  6. The lock was small enough for the cabinet. (шестой пункт я добавила из заметок, чтобы в задании было 6 предложений, как в наших правилах.)

C. Compare (заметки h1–h4; lamp test сюда не входит)

  1. 4:00 closed ink bottle → Professor Voss · supports
  2. 4:05 one note, three times → Lila Moreau · explains
  3. 4:09 key ledger → Mr Abernathy · challenges
  4. 4:11 older eye → Theo Hale · supports

D. Conclusions

  1. Mr Abernathy received the key, but we do not know if it was returned.
  2. Three sounds and shadows are not proof of three ghosts; echoes and lamps may explain them.
  3. The note was in Theo’s notebook, but its writer is still unknown.

Ключи к грамматике сверены с правилом too + adjective и adjective + enough. Противоречий в оригинале не нашла.
