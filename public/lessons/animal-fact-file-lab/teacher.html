Миссия 01 · Tiger (7 предложений)

  1. This is a tiger. (уже верно)
  2. There are tigers in China and India.
  3. There aren't any tigers in Australia. (уже верно)
  4. Tigers are orange, black and white.
  5. They've got long tails.
  6. They can jump and swim. (уже верно)
  7. Tigers are big cats.

Миссия 02 · Crocodile

  1. This is a crocodile.
  2. There are crocodiles in Australia and India.
  3. There aren't any crocodiles in Russia.
  4. Crocodiles are green and brown.
  5. They've got big teeth.
  6. They can swim and run.

Ловушки: a tiger; China and India; blue and grey; long tails; fly and sing.

Proof-check: верно только «There are crocodiles in Australia and India.»

Миссия 03 · своё досье

Четыре героя. Нужны 7 строк: имя, страна, «не живёт в», цвет, часть тела, умение, своё предложение (большая буква, точка, ≥ 4 слов).

  • panda: China / not Australia / black and white / big paws / climb trees. Своё: например Pandas eat bamboo.
  • kangaroo: Australia / not China / brown and red / strong legs / jump high. Baby kangaroos live in a pouch.
  • camel: Africa and Asia / not Antarctica / brown / a hump / walk on sand. Camels can drink a lot of water.
  • elephant: Africa and India / not Australia / grey / big ears / use their trunks. Elephants are very clever.

Домашка

01 Fix the fact file (wolf)

  1. This is a wolf.
  2. Wolves are grey and white.
  3. There are wolves in Canada and Russia.
  4. There aren't any wolves in Australia.
  5. They've got sharp teeth. (уже верно)
  6. They can run fast.

02 Write your own mini fact file. Своё, ≥ 6 предложений, в каждом большая буква и точка; есть There are / There aren't any и They've got / They can. Готового ключа нет.

03 True or False + correct

  1. Pandas live in China. — T
  2. Kangaroos are from Australia. — T
  3. There are crocodiles in Russia. — F → There aren't any crocodiles in Russia.
  4. Camels live in Antarctica. — F → Camels live in Africa and Asia.
  5. Tigers are green. — F → Tigers are orange, black and white.
  6. Elephants have got big ears. — T
