# Tutor Call — видеозвонок 1-на-1 для репетитора и ученика

Минимальный прототип: Node.js (express + ws) раздаёт страницу и выполняет WebRTC-сигнализацию.

## Возможности
- Комнаты по ссылке `/room/<id>` (на `/` создаётся случайная комната). Максимум 2 участника, третий получает «Комната заполнена».
- Видео + звук, кнопки включения/выключения микрофона и камеры.
- «Показать экран» (`getDisplayMedia` + `replaceTrack`) и «Остановить показ» — возврат к камере.
- STUN-серверы Google; место для TURN отмечено комментарием в `public/app.js` (`ICE_SERVERS`).

## Локальный запуск
```bash
npm install && npm start
```
Откройте http://localhost:3000 , скопируйте ссылку на комнату и откройте её во второй вкладке/браузере.
Порт задаётся переменной `PORT` (по умолчанию 3000). Проверка сигнализации: `npm test` (при запущенном сервере).

## Важно: HTTPS
`getUserMedia` и `getDisplayMedia` работают только в защищённом контексте — **HTTPS или localhost**.
Чтобы подключиться с другого устройства, нужен HTTPS (деплой или туннель, например `ngrok http 3000` / `cloudflared`).
Демонстрация экрана на мобильных браузерах обычно не поддерживается.

## Деплой (Render / Railway)
- **Render**: New → Web Service → подключите репозиторий. Build: `npm install`, Start: `npm start`. HTTPS и WebSocket работают из коробки.
- **Railway**: New Project → Deploy from GitHub; Railway сам определит Node.js и выполнит `npm start`, порт берётся из `PORT`.
Сервер хранит комнаты в памяти — нужен один экземпляр (без горизонтального масштабирования).

## TURN-сервер
Только STUN не хватает примерно для 10–20% сетей (симметричный NAT, мобильные операторы, корпоративные файрволы) —
тогда звонок не соединится («Не удалось соединиться»). Добавьте TURN (свой coturn, Metered, Twilio и т.п.)
в `ICE_SERVERS` в `public/app.js`. Для продакшена учётные данные TURN лучше выдавать временные, с сервера.
