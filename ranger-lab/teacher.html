Academy Stars 2 · Unit 1 · Lesson 6

Для учителя: Лаборатория рейнджера — Are there any…?

Эта страница не связана с уроком для ученика. Здесь план на 45 минут, как вести зоны и пазл, и ключи. Отдельного mp3 к уроку нет: фразы читает голос браузера (British English).

Цель

Спрашивать Are there any…? и How many… are there?, отвечать Yes, there are / No, there aren’t и There are + число. В отрицании — any.

Маршрут урока (45 мин)

  1. Вход в экспедицию, 3–4 мин. Сюжет и настройка сканера (таймер 45 минут можно поставить на паузу).
  2. Карточки правил, 2 мин. Три опоры доступны весь урок из шапки. На телефоне плавающая кнопка скрыта, чтобы не закрывать водяной знак и карточки.
  3. India Zone, 7–8 мин. Река крокодилов: ответы по опоре и два своих вопроса (8 заданий). Зона открыта сразу после брифинга.
  4. China Zone, 7–8 мин. Бамбуковый лес: выбор и дополнение фраз (8 заданий). Открывается после India.
  5. Australia Zone, 7–8 мин. Долина кенгуру: ученик сам собирает вопросы (8 заданий). Открывается после China.
  6. Пазл и Secret Zone, 10–12 мин. Собрать карту из трёх фрагментов (India / China / Australia), затем финальное сканирование без готовых вопросов (8 заданий). Секретная зона открывается после пазла.
  7. Рефлексия, 2–3 мин. Лучший вопрос (только из тех, что ученик собрал сам), уверенность и цель. Затем сертификат.

Домашка открыта сразу из шапки: 8 ответов по картинке комнаты (или своё фото) и свой 8-строчный мини-диалог. Форматы не совпадают с классными миссиями.

Аудио

Своего mp3 нет. Кнопки «Прослушать фразу» и «Прослушать диалог» используют голос браузера (speechSynthesis, en-GB, чуть медленнее обычного). Если браузер не говорит, ученик читает текст сам.

Как устроены зоны и пазл

На сканере видны числа: India — 4 крокодила (2 под водой), 6 птиц, 0 панд; China — 2 панды, 8 птиц, 0 крокодилов; Australia — 2 кенгуру, 3 птицы, 0 лис; Secret Zone — 2 лисы, 5 птиц, 1 паук, 0 панд.

Слоты пазла всегда слева направо: India, China, Australia. Фрагменты в рюкзаке перемешаны; при «Начать заново» перемешиваются снова. Кнопка «Разобрать и начать заново» только снимает фрагменты с карты, порядок в рюкзаке сохраняется.

Что проверять в свободных ответах

Проверка мягкая к регистру, апострофам, точкам и лишним пробелам, но не к грамматике Are there any / Yes, there are / How many. Числа засчитываются словом и цифрой: two / 2, six / 6, eight в полном ответе, aren't / aren’t / are not.

Ключи

India Zone · Река крокодилов

  1. Are there any crocodiles? — Yes, there are.
  2. How many crocodiles are there? — There are four crocodiles.
  3. Are there any pandas? — No, there aren’t.
  4. There ___ four crocodiles. — are
  5. Are there any birds? — Yes, there are.
  6. There are ___ birds. — six / 6
  7. Собрать: Are there any crocodiles?
  8. Собрать: Are there any pandas?

China Zone · Бамбуковый лес

  1. Are there any pandas? — Yes, there are.
  2. Are there any crocodiles? — No, there aren’t.
  3. There are ___ pandas. — two / 2
  4. There ___ any crocodiles. — aren’t / aren't / are not
  5. How many birds are there? — There are eight birds.
  6. How ___ are there? — many
  7. Are there any birds? — Yes, there are.
  8. There aren’t ___ crocodiles. — any

Australia Zone · Долина кенгуру

  1. Собрать: Are there any kangaroos?
  2. Are there any kangaroos? — Yes, there are.
  3. Собрать: How many kangaroos are there?
  4. There are ___ kangaroos. — two / 2
  5. Собрать: Are there any foxes?
  6. Are there any foxes? — No, there aren’t.
  7. Собрать: Are there any birds?
  8. There are ___ birds. — three / 3

Secret Zone

  1. Собрать: Are there any foxes?
  2. Are there any foxes? — Yes, there are.
  3. Собрать: How many foxes are there?
  4. There are ___ foxes. — two / 2
  5. Собрать: Are there any pandas?
  6. Are there any pandas? — No, there aren’t.
  7. Собрать: Are there any birds?
  8. There are five birds. (полный ответ)

Последний пункт: в задании нужен полный ответ There are five birds.

Домашка, часть 1 (картинка комнаты)

  1. Are there any books? — Yes, there are.
  2. How many books are there? — There are five books. / 5
  3. Are there any cats? — No, there aren’t.
  4. How many balls are there? — There are two balls. / 2
  5. Are there any pencils? — Yes, there are.
  6. How many pencils are there? — There are twelve pencils. / 12
  7. Are there any birds? — No, there aren’t.
  8. There aren’t ___ cats. — any

На картинке: 5 книг, 12 карандашей, 2 мяча; кошек и птиц нет. Часть 2 ученик пишет сам: своя зона и диалог из 8 реплик (Are there any…?, короткий ответ, How many…?, число, вопрос про то, чего нет, отрицательный ответ, ещё один вопрос и финальный ответ).
